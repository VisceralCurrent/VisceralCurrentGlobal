# Visceral Current Multidimensional University

A React/Next.js ecosystem designed as a living matrix for self-discovery across nine domains.

## Architecture

- 9 domains arranged in a 3x3 matrix.
- Mastery 360 logic that combines Infinite Spirit + Understanding + Integration.
- Non-linear navigation with a constellation-style map.
- Interactive transitions with Framer Motion.

## Setup

1. Open the folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.

## Project structure

- `app/` - Next.js app pages and layout.
- `components/` - Mastery provider, domain cards, and map visualization.
- `lib/` - Visceral flow utility hook.

## Notes

This project is a foundation for a modular fractal architecture with a closed circuit of 3s and a 9x9 sovereign matrix.
