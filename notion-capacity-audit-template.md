# Visceral Current | Master Capacity Audit Notion Template

## 🎯 Objective
A reusable, 80% pre-filled Notion template for delivering the 48-hour Capacity Audit as a productized, high-leverage client service.

- Rapid onboarding (Day 0-1)
- Concrete diagnostic structure (Day 1-2)
- Dynamic delivery & handoff (Hour 48)

---

## 🧱 Template Top-Level Structure

1. **Command Center (Origin)**
2. **Flow State Map (Coordinates)**
3. **Evolution Blueprint (Phase Shift)**
4. **Library (Force vs Power Playbook)**
5. **Admin + Client Brief**

---

## 1) Command Center (Origin)

**Purpose**: anchor the company in the grounded, undeniable `ν` truth.

### Sections
- `KLI: Key Logical Identity` block (text, large, bold).
- `Resonance Scorecard` (formula + manual values): internal signal vs external signal.
- `How to use this board` / walkthrough.
- `Executive Summary` (template): 3 bullets + quick 2-line POV + 48-hour result statement.
- `Embedded Loom` link.

### Properties (if page has database)
- `Start Date` (date)
- `Client` (text)
- `Founder` (person)
- `Visceral Signal` (select: 
  - high
  - medium
  - low)
- `Phase Visibility` (select: origin/coords/transmute/dominion)

---

## 2) Flow State Map (Coordinates)

**Goal**: translate physical process friction into actionable database entries.

### Database: Capacity Ledger

Properties:
- `Heavy Gear` (title): process/meeting/task.
- `Current State` (select): `Force`, `Power`, `Hybrid`.
- `Entropy Score` (number 0-10).
- `Leak Type` (select): `people / process / product / platform`.
- `Codex Solution` (text).
- `Owner` (person).
- `Status` (select): `Identified`, `Piloting`, `Deployed`, `Done`.
- `Time Saved` (number in hours forecast).

### Views
- Board by `Current State`.
- Table with sorting by `Entropy Score` desc.
- Calendar (optional) by `due date`.

---

## 3) Evolution Blueprint (Phase Shift)

**Goal**: program the exact 90-day roadmap with jump-start micro-actions.

### Database: Pivot Timeline

Properties:
- `Avoided Pivot` (title).
- `Phase` (select): Day 1-14 / 15-30 / 31-90.
- `Priority` (select): Critical / High / Medium / Low.
- `Component` (select): Product, GTM, Ops, People, Brand.
- `Trigger` (text): what condition opens this.
- `Action` (text): exact high-flow protocol.
- `Impact Metric` (text): e.g., “drop meeting load 22%”, “move from 7 to 12 NPS” etc.
- `Completion` (checkbox).
- `Retrospective` (text).

### Views
- Timeline (phases color-coded).
- Board (phase lane).

---

## 4) Library (Force vs Power Playbook)

**Goal**: reusable content that reduces cognitive overhead. Drag-and-drop “evidence-based actions.”

### Database: Power Protocols

Properties:
- `Challenge` (title) e.g., “Manager overload in weekly syncs”.
- `Force Symptoms` (text).
- `Power Outcome` (text).
- `Protocol` (text).
- `Estimated Capacity Change` (number % or hours).
- `Category` (select): Process, Culture, Product, Growth.

### Views
- Table (by category).
- Gallery (highlight top protocols).

---

## 5) Admin + Client Brief

**Purpose**: Systematize client communication.

### Pages
- `Kickoff Agenda` (template) with 60-minute structure.
- `Intake questions (from protocol)` (copy/paste): 4 domains: Origin, Coordinates, Frequency, Phase Shift.
- `Client assets` checklist (url links to site/socials/matrix).
- `Deliverables` table (small project tracker).
- `Observations + Advice` (running log).
